# References and project history

## Original framework publication

P. E. Hadjidoukas, P. Angelikopoulos, C. Papadimitriou, and P. Koumoutsakos, **Π4U: A high performance computing framework for Bayesian uncertainty quantification of complex models**, *Journal of Computational Physics*, 284, 1–21 (2015). [DOI: 10.1016/j.jcp.2014.12.006](https://doi.org/10.1016/j.jcp.2014.12.006).

Please also cite publications for any specific algorithms or runtime components used in research.

## Historical and present development

Pi4U originated at CSELAB, ETH Zurich. The [CEID-HPCLAB/pi4u](https://github.com/CEID-HPCLAB/pi4u) repository is a continuation developed at the University of Patras, preserving the original contributors' attribution and applicable license notices.

The earlier Pi4U website was generated using MkDocs with the Material theme. The repository includes a [consolidated documentation report](https://github.com/CEID-HPCLAB/pi4u/blob/main/doc/documentation_report.md) capturing that earlier website. Its historical paths and commands are not guaranteed to match the current source layout; consult the current engine README files instead.

For support, use the [Pi4U issue tracker](https://github.com/CEID-HPCLAB/pi4u/issues).
